## 🚀 Quick Links

### Getting Started
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python run.py`

### Building for Android
1. Install buildozer: `pip install buildozer`
2. Build APK: `buildozer android debug`
