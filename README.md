# CalorieApp Testnet archive

**Historical prototype · test assets only · separate from the current CalorieApp**

This repository preserves earlier Kivy/KivyMD experiments with XRP Ledger interfaces and food tracking. It explains the project's development history. It is not the current CalorieApp V2 runtime, a maintained Mainnet wallet, a live exchange or a payment service.

[Current food webapp](https://calorietoken.net/index.php/calorieapp/) · [Current source](https://github.com/CalorieToken/CalorieApp) · [Whitepaper and roadmap](https://github.com/CalorieToken/Publications)
